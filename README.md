# Suntrust Parkview Mockup Site

A responsive academic website showcasing the studio room, property, amenities, and neighborhood around Suntrust Parkview in Manila.

**Academic project:** This website is not affiliated with or endorsed by Suntrust Parkview Hotel.

## Live website

https://suntrust-parkview-showcase-nov2026-g7p.quickbetta131.chatgpt.site

## Files and local preview

`index.html` contains the complete website, including its CSS, JavaScript, and embedded photographs. No build step or package installation is required.

Open `index.html` in a browser, or serve this folder locally:

```sh
python -m http.server 8000
```

Then open http://localhost:8000.

## Behavior

- Responsive Home page and six content tabs.
- Room gallery, interactive site-plan locations, and neighborhood filters.
- Rate Us opens the supplied Google Form.
- The inquiry tool prepares a local, copyable message; it does not submit or store inquiries.
- Google Fonts and the embedded Google Maps view require an internet connection.

## Images and information

Image credits and information sources are included in the website footer. Third-party images and marks retain their source rights and licenses. Some operator-specific details and reception/parking photographs remain unavailable, as indicated on the site.

## Hosting

Upload `index.html` to a static web host. The current live website is hosted through Sites; publishing changes to this GitHub repository alone does not update that deployment.
